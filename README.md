# PromptingManagement26Q4

Скилл для создания и редактирования промптов. Помогает объяснить модели, какой результат нужен, какие факты ей понадобятся и где у неё есть свобода решения. Подходит для разовых запросов, системных инструкций и агентных скиллов.

Все инструкции и ссылки на руководства OpenAI и Anthropic собраны в [SKILL.md](SKILL.md). Скилл написан по-английски. Язык создаваемого промпта определяется задачей.

> Вот мой промпт для генератора предметов и три его ответа. Во всех трёх модель скопировала механику из примера. Помоги передать, что именно в нём важно, и оставь выбор механики модели.

Подход вырос из работы над [InfiniCrafterLocal](https://github.com/Xipong/InfiniCrafterLocal/blob/main/LocalGenerator/infini_local/AGENTS.md).
